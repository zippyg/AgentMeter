# Vision

AgentMeter is a local-first control surface for AI coding limits, credits, spend, status, and reset windows. It should make the current state visible without moving provider credentials off the Mac.

## Merge By Default

- Performance improvements that keep the app idle-light.
- Bug fixes with clear cause and bounded risk.
- Provider support that follows existing descriptor, strategy, settings, and test patterns.
- Small UI or UX tweaks that improve repeated daily use.
- Documentation fixes that make setup, privacy, or provider confidence clearer.

## Needs Sign-Off

- New auth flows or provider endpoints.
- Package, dependency, signing, notarization, or toolchain changes.
- Broad refactors or architecture changes.
- Behavior changes that affect provider auth, data storage, local bridge access, or user privacy.
- Provider additions that need new host APIs, bespoke UI, broad filesystem access, or unclear auth/privacy behavior.
- Anything that would publish, push, create a public repo, or distribute binaries.
